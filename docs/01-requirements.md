### Pending NFR changes

- **Model files (N2, N4):** the procedural viewer has no model files. Replace "base model load" and "5 MB per model" with time to first render and a total viewer asset budget. Any 5 MB limit applies to textures and environment maps.
- **Uptime and backups (N36, N95):** free tiers cannot meet them during evaluation. Either evaluate on a paid Supabase plan or limit these targets to production. Name an uptime monitor.
- **Chatbot language (N39, N40):** remove the Filipino/Taglish exclusion. The 50-query test set includes a defined Filipino/Taglish share (proposed 30%). Report accuracy separately.
- **Rate limits (N54):** add a per-customer hourly message limit and a maximum message length. Numbers are open.
- **Owner security (N68):** owner account requires TOTP. The 30-minute session may be too short for the owner (**Open**).
- **Claim code (N90):** unguessable and unique per item.
- **Uploads (N107):** owner in-store photos accept JPG and PNG only, 5 MB, owner-only.
- **Validation (N22):** reference numbers cannot be reused.
- **Maintainability (N105, N114):** owner manages options and rates only. New ring styles need a developer and are outside the study.
- **Functional Suitability (N63, N98):** redo the "100% of Must" criterion after re-grading. The 20 configurations cover rings.
